## P0：构建、首次使用和权限

- [ ] 本机架构一致：Node、Electron、helper 与 FFmpeg 匹配，无 Rosetta 混装；原生组件、共享测试和 Mac 分发包均构建成功。
- [ ] 打包 app 从“应用程序”启动正常，菜单栏图标、主页、设置及退出可用。
- [ ] 引导可以添加 ASR 供应商并保存，配置会跟随实际选择，不被页面切换重置；文本供应商独立。
- [ ] 麦克风授权允许、拒绝、撤销后重新授权都有清晰结果；无崩溃或“看似录音却没有数据”。
- [ ] 屏幕/系统音频授权有准确入口；Terminal、Electron、最终 app、helper 的权限归属分别确认。
- [ ] 仅系统音频模式不请求或打开麦克风；缺少屏幕权限时给出准确提示。
- [ ] 辅助功能未授权时不会输入到错误应用；授权后可重试，应用不会误报输入成功。
- [ ] 源码和打包版分别测试；记录未签名 app 的系统提示，不全局禁用 Gatekeeper。

## P0：短语音输入完整性

- [ ] 主页与设置各自处于显示、最小化、隐藏到菜单栏三种状态时，实际按系统快捷键均可呼出小窗。
- [ ] 编辑快捷键时暂停捕获；失焦、最小化、隐藏、切换标签后恢复；快速操作不会永久失效。
- [ ] Fast 与 Stable 分别成功；Enter 结束并输入，Escape/取消不输入；稳定模式保留句尾及完整含义。
- [ ] 原目标应用被正确恢复；中文、英文、数字、emoji、标点、换行、长段落均完整输入，不误触发送/提交。
- [ ] 至少测试 TextEdit、浏览器 textarea、contenteditable 及一个实际常用聊天/编辑软件，并记录各自结果。
- [ ] 输入前设置测试剪贴板，输入后检查文字和格式未被自动改写；只有主动点击复制才改写剪贴板。
- [ ] 原应用关闭、不可编辑、焦点变更或权限不足时安全失败，展示识别结果供用户操作，无错误成功计数。
- [ ] 连续两次不同录音互不带入前次对话或转写上下文；识别历史保留完整原文和整理稿。

## P0：会议音频与转录持久化

- [ ] 仅麦克风、仅系统、双轨分别有正确音源和可播放录音，不把双轨当作说话人分离。
- [ ] 与腾讯会议等软件同时使用麦克风时，两边都能收到声音；使用耳机检查系统与麦克风重复采集。
- [ ] 真实阿里实时模型显示草稿，再按顺序确认全文；短暂停顿、长句、静音后恢复不丢尾句。
- [ ] 跨过至少一次长连接轮换（建议连续 30 分钟以上），无持续预览空白、重排、重复或丢失。
- [ ] MiMo 非实时备用按设置间隔提交；界面不假装为 WebSocket 实时，失败片段能够停止后重试。
- [ ] 断网/短暂失败时本地录音与 Markdown 热保存继续；复网后确认失败范围与重试行为，不把缺口显示为完成。
- [ ] 暂停/继续保持同一会话，时间空洞有记录；暂停后直接停止也能封存尾段。
- [ ] 阿里云实时会议连续录制 30 分钟以上，暂停 8–10 分钟后继续讲话；新草稿及时出现，反复暂停/继续仍可用，完整音频保留暂停时间轴且确认文字定位准确。分别记录单轨与双轨结果。
- [ ] 停止后完整音频可播放，开头和尾部都存在；原生 PCM 未被重采样覆盖，ASR 分段未裁剪本地音频。
- [ ] 测试会话中模拟 app/helper 退出后，已有数据仍可读、检查点可恢复；不要用私人真实会话做破坏测试。
- [ ] 保存目录不可写、外部修改 Markdown 或磁盘故障时有准确提示，不静默丢数据或覆盖用户编辑。

## P1：窗口与显示

- [ ] 小窗在 TextEdit/浏览器/聊天输入框附近出现，几何不可得时回退到屏幕可见区域；不读输入框内容。
- [ ] 冷启动、第二次呼出、主界面已打开三种状态录屏逐帧检查，无旧页面先闪、消失再出现或文字二次淡入。
- [ ] 多屏、Retina/非 Retina、Dock/菜单栏附近和屏幕边缘没有越界；录制中保留手动移动位置。
- [ ] 小窗透明背景、圆角、频谱、指示灯对齐及固定尺寸符合当前设计，长文字滚动而不撑大窗口。
- [ ] 主页、设置、文件、会议与悬浮窗顶部均可拖动；系统启用三指拖动时工作，按钮和输入框仍可操作。
- [ ] 窗口边缘缩放光标正常，最小化/最大化/恢复可用，缩放后文字、工具栏和正文不遮挡。
- [ ] 文件与会议的模型/历史侧边栏可收起、展开及调宽；缺配置时模型设置明确可见。
- [ ] 会议开始后自动悬浮，能置顶、暂停、停止、回详情；位置尺寸记忆正确，多屏变化后仍可见。
- [ ] 会议极小窗仅显示实时内容；鼠标移出控件隐藏，移入恢复背景和控件；字体/透明度设置有效。

## P1：文件、摘要、设置与更新

- [ ] 音频及包含音轨的视频都可导入；导入新文件会更新标题，旧会话不被覆盖；可选择有效 ASR 模型。
- [ ] 文件与会议生成摘要都采用思维导图 + 连贯正文，不退回旧纪要列表；引用可定位到证据区间。
- [ ] 会议左下角切换“摘要模型”后，切页、重新启动应用及新建会议仍采用已保存的供应商和模型；相同模型 ID 的不同供应商不会混淆，表达整理模型仍独立。
- [ ] 未勾选 MiMo 复核不发送额外 ASR；勾选后完整音频分段覆盖，原文、复核与摘要分别保留。
- [ ] 摘要开始后切换主页/设置/其他页面仍在后台进行；返回可见进度与结果，网络失败有可恢复状态。
- [ ] 至少一个 Chat Completions 和一个 Responses 文本配置能调用；动态模型获取、上下文/输出参数及 URL/Key 隔离正确。
- [ ] MD/TXT/Word 导出可打开，正文和导图/层级内容完整；旧历史仍可阅读，再生成不覆盖旧产物。
- [ ] 菜单栏识别历史入口及可选快捷键可用；输入/会议/历史快捷键冲突有反馈。
- [ ] 打包版开机自启开关读取系统状态；登录后仅驻留菜单栏，不自动录音或打开主页；源码不注册启动项。
- [ ] 关于与更新可展示更新日志；架构清单选择正确。当前未签名包的更新/替换行为据实记录，不能仅凭请求成功判定安装成功。
- [ ] 从首个独立通道版升级到后续 Mac 版：Intel / Apple Silicon 只收到对应 Mac 包，显示明确的 Mac 改进说明，下载校验和实际安装通过；仅 Windows 发布时 Mac 无新版本提醒，Mac 发布不改变原 Windows latest。旧 Mac 首次手动安装迁移单独记录。

## P2：韧性与分发

- [ ] 外置/蓝牙麦克风切换、设备拔插、耳机断开、显示器变化均可预期处理，不遗留采集进程。
- [ ] 睡眠/唤醒后权限、全局快捷键与录音状态一致，失败有提示，不宣称睡眠期间录到了未采集内容。
- [ ] 长时测试内存与 CPU 无持续异常增长，队列和断线不会导致无界缓存；保存文件可回放并对齐文本。
- [ ] 若启用 Developer ID 签名/公证，嵌套 helper、entitlements、TCC、更新和干净账号首次启动重新验收。
