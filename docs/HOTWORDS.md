# Dictation Hotwords / 语音输入热词

## 使用

在“设置 → 热词词典”中维护本机词库，入口位于“语音识别”和“表达整理”之间。添加正确的人名、产品名或术语；可以修改、停用或删除。总开关控制后续语音输入请求是否使用词库；正在进行的 ASR 连接使用创建时的词库快照。

### 批量导入与删除

点击“导入词库”，选择本地文件，检查有效、重复、已存在及无效词条的统计后确认。预览不会写入词典；取消不改变现有词条。导入不会上传或修改源文件，词库解析在独立工作线程中完成。

- TXT：每行一个词，支持 UTF-8、带 BOM 的 UTF-16，以及 GB18030。空行忽略，不按空格拆开英文术语。
- XLSX、CSV、TSV：优先使用首个非空行中的“词条”“热词”“词语”“word”“term”等命名列；没有上述表头时读取第一列，并保留第一行。XLSX 读取全部工作表，请勿把非词库工作表放入导入文件。数字、日期不作为词条；不会执行公式或访问表格链接。旧 `.xls` 请先另存为 `.xlsx` 或 CSV。
- 搜狗 `.bin`：支持已验证的 SGPU 备份格式，依据记录索引和长度读取词条，不扫描任意字符串。其他版本或加密格式会明确报错；`.scel` 暂不支持。
- 单文件最多 16 MiB、10 万条记录；XLSX 解压内容最多 64 MiB、1 万个 ZIP 条目、每行最多 256 列。解析最长 30 秒，异常文件不阻塞录音。
- 相同词条按规范化后不区分大小写去重，保留现有词条的启停状态。超过词典剩余容量时拒绝整个导入，不静默截断。
- 可搜索词条、每页显示 100 条，勾选单条、当前页或选择全部搜索结果后批量删除；未输入搜索词时，“选择全部搜索结果”会选择整个词典。选择可跨页保留，删除前显示确认；只删除本地词典中的条目，不删除原始词库文件。

词典容量与请求容量独立：本地最多 10 万条，同时最多启用 100 条。导入时填满剩余启用名额，其余词条以停用状态保存；要启用其他词条，请先停用已有词条。不会将整份大词库加入 ASR 请求或表达整理提示词。

Windows 可单独开启“收集修正候选”。此选项默认关闭。开启后，只在本应用成功输入文字后短时观察同一个输入控件内的本次文字范围。候选需要用户确认，才会加入可发送的词库；忽略的相同词对不会反复出现。修正检测是保守启发式，候选不代表模型一定识别错误。

观察有范围、时长和文本大小限制；控件不支持 UI Automation、密码框、目标改变、文本被发送后清空或无法确认原输入范围时跳过。不会使用全局键盘记录、读取剪贴板或扫描整个文档。不同编辑器的支持程度不同；未收集到候选时仍可手动添加词条。

第一版观察窗口最长 45 秒，原输入至少 12 个字符、最多 4096 个 UTF-16 单元，首尾各四个字符必须唯一且保持不变。仅收集中间词语的替换，等待文本和光标稳定约两秒后再核对一次，每次输入最多收集一条候选。中间选词会等待，选到范围之外或修改首尾则停止；新增长段落、纯插入或删除、数字变化等不作为候选。部分富文本编辑器不能保持独立文本范围，或换行/Unicode 字符计数不同，第一版会跳过这些情况。

“稳定两秒”是停止编辑的启发式，并不能判断用户的最终意图。如果应用发送文本后仍保留原文本、焦点与范围，观察器无法可靠得知发送动作；确认候选时仍需用户判断。关闭词典总开关也会暂停修正观察。

设置中的观察说明会显示最近一次状态。测试发现部分 Electron/Chromium 输入框编辑后会使旧的 UIA 范围失效，此时提示手动添加，绝不回退到整页/整篇文档读取。目前不保证 Codex 等所有聊天编辑器都能自动收集；同窗口重复焦点通知不会单独触发取消，真正切换窗口或检测到焦点控件变化则停止。

## 请求边界

- 本轮先用于短语音输入法，不改变会议或文件转录的请求内容。
- `qwen-audio-3.0-asr-flash-streaming` 及其日期版本通过 `parameters.vocabulary` 携带即时热词，普通权重为 4。北京和新加坡公共端点适用；已知不支持的美国端点及新加坡子业务空间不发送该字段。自定义代理需要兼容对应模型的参数。
- `qwen3-asr-flash`、旧 `/realtime` 协议、MiMo 等未核实兼容的 ASR 不接收这个字段；不会静默更换模型或供应商。
- 稳定模式的表达整理器收到已启用、已确认词条作为术语参考。只提供词形，不发送候选错误词对、以前的句子或输入窗口内容。不使用正则全局替换。
- 候选收集本身不调用云端模型，不产生额外 ASR/LLM 请求。热词和人工确认不能保证模型每次都采用正确词形。

## 存储与兼容性

词库单独保存在 Electron 用户数据目录的 `hotwords.json`，不与供应商 API Key 合并。只持久化词条、词条启停状态、待确认的短词对和次数、忽略词对的摘要值。完整观察文本只用于短期内存比较，不写入该文件或日志。

最多 10 万个正式词条、100 个启用词条和 100 个候选。含非 ASCII 字符的词条最长 15 字符；纯 ASCII 词条最多 7 个空格分隔片段，另有本地 80 字符上限。排除控制符、明显凭证、提示词标签和非词语输入。文件损坏时停用词库并报错，不覆盖损坏文件；写入采用串行临时文件加重命名，失败不改变已生效词库。

词库、设置界面及供应商适配是共享模块。输入修正观察器是 Windows 原生模块，macOS 不启动此观察器；macOS 原生实现与硬件验收由协作者维护。共享测试检查跨平台兼容性，不等同 macOS 真机验证。

## 官方接口依据

2026-11-05 核对阿里“提升识别准确率”文档，参见 https://help.aliyun.com/zh/model-studio/improve-asr-accuracy 。即时热词字段为 `parameters.vocabulary`，不是 `vocabulary_id` 或对话历史。这里的 100 词是产品第一版上限，低于文档的模型上限。

Windows 文本范围依据 UI Automation Text/TextRange 接口，参见 https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-about-text-and-textrange-patterns 。外部应用可能不完整实现该接口，因此观察失败不阻塞语音输入。
