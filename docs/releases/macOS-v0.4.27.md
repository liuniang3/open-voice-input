# Open Voice Input Mac 版（macOS）v0.4.27

发布日期：2026-10-22。提供 Apple Silicon arm64 和 Intel x64 安装包，通过独立 Mac 通道更新。

## 本次改善

- 会议实时转录页点击左侧历史记录后，侧边栏保持展开，可以连续切换、浏览不同会议。
- 再次点击当前记录也保持展开；需要收起时，使用侧栏折叠按钮或“历史记录”开关手动操作。宽屏和窄屏采用相同行为。

## 安装与更新

已安装 Mac 版 v0.4.26 的用户可通过应用内独立 Mac 更新通道获取本版，也可下载对应架构 DMG 手动替换。v0.4.25 及更早的 Mac 版本须首次手动安装。配置、历史和原始录音保存在用户数据目录，升级时保留。

本版只发布 Mac 安装包。GitHub Release 保持 prerelease 且 `latest=false`；Mac 只读取独立的架构清单，现有 Windows 更新通道不受影响。

## 验证与限制

- 会议 UI 28/28 项、完整共享回归 77/77 个脚本通过，覆盖宽/窄屏连续选择、重复点击、当前项标记、展开偏好保存和手动折叠/展开；浏览历史不会启动录音或 ASR。
- 本机 arm64 DMG/ZIP 打包通过，包含敏感信息检查、helper/FFmpeg 构建与检查和完整回归；镜像内修复源码、Mac 更新源、原生资源、ZIP/DMG 及更新元数据校验通过。两架构构建与发布的实际结果见 Mac Release Actions，开发记录见 `docs/MACOS_DEVELOPMENT.md`。
- 本版**未签名、未公证**。本次修复的验证为 UI 状态回归；真实阿里云长会议、权限、真实采集、文字输入及应用内更新安装仍按真机清单验收。
