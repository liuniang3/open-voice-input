# Open Voice Input v0.4.19

本次更新集中优化文件转写与实时会议工作区：设置和历史记录放进可折叠、可调宽的侧栏，原文与摘要随窗口自适应，并修复连续导入文件时沿用旧标题的问题。

## 工作区布局

- 文件转写、实时会议共用侧栏交互：历史记录与转录模型设置可独立展开、向左收起，支持拖动边缘或使用方向键调整宽度，自动记住宽度和展开状态。
- 窄窗口使用可关闭的侧栏抽屉，可点击遮罩或按 Esc 关闭；会议悬浮窗隐藏侧栏。
- 本地 ASR 配置缺少 Key、地址无效或模型不兼容时，进入工作区或切换模型会展开设置并给出提示；例行刷新不会反复打开手动收起的侧栏。
- 原始转写、文件结果和会议摘要随整个窗口调整显示区域，长内容在区域内部滚动，取消单独的阅读区高度调节。
- 会议悬浮窗保留实时草稿与历史内容的比例调节。详细工作区去掉重复的会议标题，将历史和模型设置入口放在左侧。
- 悬浮窗按钮位于转录区域上方左侧；原文 Markdown 入口移到状态操作行。完整录音按麦克风、系统声音或混合录音命名。

## 文件操作与修复

- 转写、摘要操作在宽窗口中按组排成一行，状态、模型、MiMo 复核及操作紧挨排列；窄窗口按组换行。
- 隐藏无法使用的重试、取消图标，以及已完成转写的开始按钮；失败和处理中仍可执行相应的重试或取消操作。
- 当前处理状态使用醒目的提示条：处理中显示加载图标与浅蓝背景，完成为绿色，警告为黄色，失败为红色。长提示自动换行，动画遵循系统减少动态效果设置。
- 修复导入新文件时自动继承旧记录标题的问题。默认使用新文件名，手动填写的标题仅用于本次导入；取消或失败时保留标题草稿。
- 切换历史记录、刷新列表不会覆盖为下次导入填写的标题；导入接受时也不会清除等待期间新写入的标题。

## 验证与下载

- 本地完整共享回归测试 `67/67` 通过；浏览器检查覆盖 Windows/macOS 界面样式、宽窄窗口、侧栏缩放与记忆、连续导入标题、状态提示和后台摘要。
- 发布构建分别运行 Windows x64、macOS Intel x64 和 Apple Silicon arm64 测试与打包。
- 安装包不包含用户 API Key、本地设置、音频、转写记录或诊断截图；提交和打包输入经过敏感信息检查。
- Windows 提供安装版和便携版 EXE；macOS 提供 Intel / Apple Silicon 的 DMG 与 ZIP，附自动更新元数据及 SHA-256 校验文件。
- macOS 包仍未签名；构建通过不代表原生录音、权限、粘贴和视觉效果已完成真机验证。

## English Summary

- File/live workspaces gain independently collapsible and resizable history/model sidebars, remembered locally, with dismissible drawers in narrow windows and safe configuration hints.
- Transcript and summary reading areas adapt to the window instead of using separate fixed heights; the floating draft/history split remains adjustable.
- File transcription and summary controls stay grouped and adjacent, with contextual retry/cancel actions and more visible processing/success/error feedback.
- New file imports use their own filename rather than inheriting the selected history title. Optional import titles are consumed once, retained on cancellation/failure, and isolated from history refreshes.
- Shared regressions passed locally (`67/67`); release builds cover Windows x64 and unsigned macOS Intel/Apple Silicon packages. Native macOS behavior still requires hardware validation.
