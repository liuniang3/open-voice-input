# Open Voice Input v0.4.24

本次更新修复实时会议页面无法开始转录的问题，增加开机自启，并统一会议和文件转写的模型设置入口。

## 实时会议启动修复

- 上次会议遗留的失败或待重试识别片段不再阻止新会议开始，页面与托盘菜单使用一致的启动规则。
- 正在录音、音频尚未保存完成、Markdown 保存失败或正在生成摘要等情况下，仍保留启动限制，并显示具体原因。
- 之前会议的完整音频、原文和重试记录保留。开始新会议不会自动重试旧片段。

## 开机自启

- 在设置的“关于与更新”中增加开机自启开关，默认关闭，支持 Windows 安装版、便携版和 macOS。
- 开机启动后只初始化托盘和快捷键，不自动打开主页，也不自动录音；手动打开应用仍正常显示界面。
- 开关读取系统实际状态。Mac 需要系统批准时会显示提示；Windows 便携版使用便携程序路径。
- 开机自启适用于打包后的应用，从源码或 VBS 启动时不会注册系统启动项。

## 操作布局

- 文件转写和实时会议的“转录模型设置”位于开始按钮左侧，使用调节滑块图标。
- 窄窗口中相关按钮保持成组，便于查找和操作。

## 验证与下载

- 74 个共享回归脚本通过，Windows x64、Intel Mac x64 和 Apple Silicon Mac arm64 的 CI 均通过；正式发布构建会再次执行测试与敏感信息检查。
- Windows：选择 `Open-Voice-Input-Setup-0.4.24-x64.exe` 安装版，或 `Open-Voice-Input-Portable-0.4.24-x64.exe` 便携版。
- Apple Silicon Mac：选择文件名含 `arm64` 的 DMG 或 ZIP；Intel Mac：选择含 `x64` 的 DMG 或 ZIP。macOS 包目前未签名、未公证；原生采集、权限、粘贴和开机自启仍需要真机验收。
- 包含自动更新元数据、blockmap 和 SHA-256 校验文件。已有用户可通过“关于与更新”检查更新；未签名 Mac 更新仍需替换下载后的应用。
- 升级保留本机供应商配置。提交与发布包不包含 API Key、个人配置、真实录音或转写、诊断截图及供应商响应正文。
