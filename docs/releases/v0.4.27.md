# Open Voice Input v0.4.27 · Windows

本次 Windows 更新新增独立热词词典、批量导入与删除，并修复输入法未唤醒时隐藏窗口仍持续重绘的问题。

## 降低空闲 CPU 占用

- 语音输入浮窗隐藏后停止指示灯动画、频谱显示和滚动刷新，并恢复后台节流；再次呼出时恢复显示。
- 主页统计刷新、会议页面计时与轮询在窗口隐藏或最小化后暂停，恢复显示时读取最新状态。
- 后台录音、实时识别、Markdown 自动保存和摘要任务继续独立运行，不因隐藏界面而中断。
- 修复从最小化主页呼出语音输入法时，主窗口可能短暂闪现的问题。
- 本机隔离短时对照测试中，相关测试进程的整机 CPU 占用由约 1% 降至约 0.3%。实际数值受电脑、任务和运行环境影响，不保证空闲占用始终为零。

## 独立热词词典

- 左侧设置新增“热词词典”，位于“语音识别”和“表达整理”之间，修改即时保存。
- 支持词条添加、编辑、启停、搜索、分页及批量删除；可选择当前页或全部搜索结果，删除前显示确认。
- 支持 TXT、XLSX、CSV、TSV，以及搜狗 SGPU `.bin` 备份格式的本地导入。预览显示有效、无效、重复和已存在条目，确认后一次性保存，源文件保持不变。
- 本地最多保存 10 万条词语，同时最多启用 100 条供识别和表达整理请求使用；超出启用名额的导入词条先停用保存。词库不会整份加入模型请求。
- TXT 支持 UTF-8、带 BOM 的 UTF-16 和 GB18030。表格优先读取“词条”“热词”等命名列，没有上述表头时读取第一列；XLSX 读取全部工作表。
- 单文件最多 16 MiB、10 万条记录。旧 `.xls` 请另存为 XLSX 或 CSV；搜狗其他二进制版本、加密备份和 `.scel` 暂不支持。异常或超限文件不会部分覆盖已有词库。

## 热词的使用与隐私

- 短语音输入中，已启用词条可供稳定模式的表达整理作为术语参考；支持的 `qwen-audio-3.0-asr-flash-streaming` 及日期版本通过即时词表使用热词。普通 Qwen3-ASR Flash 批量识别、MiMo 等未核实兼容的 ASR 保留现有请求格式。
- 新增默认关闭的 Windows 输入修正候选收集。只短时观察本次输入的文本范围，候选须人工确认后才加入词典；不支持可靠文本范围的编辑器会跳过，仍可手动添加词条。
- 候选观察不读取剪贴板、不使用全局键盘记录，也不扫描整篇文档。完整观察文本不写入词库、日志或模型历史。
- 词库保存在本机用户数据目录，与供应商 API 凭证独立保存。已启用词条会按上述规则发送给所选识别或表达整理服务。

## 验证与下载

- 82 个共享回归脚本通过；Windows 原生测试验证持续音频采集、完整文字输入、Esc 取消、重复唤醒、最小化恢复及隐藏后的动画停止。
- 词库测试覆盖导入格式、损坏与超限文件、失败重试、跨页删除和重启持久化；浏览器检查覆盖桌面与窄窗口。
- Windows、Linux、Intel Mac 与 Apple Silicon 的共享兼容性 CI 已通过。macOS 原生实现和硬件验收由协作者维护，本次只发布 Windows 安装包。
- 安装版：`Open-Voice-Input-Setup-0.4.27-x64.exe`。
- 便携版：`Open-Voice-Input-Portable-0.4.27-x64.exe`。
- 已安装 Windows 版可在“关于与更新”中检查更新。附带 `latest.yml`、blockmap 和 SHA-256 校验文件；Windows 包仍未签名。
- 升级保留本机 API 配置、词典、历史记录和录音。提交与发布包不包含个人配置、密钥、真实录音、转写正文或诊断截图。

## English

- Windows-only release with a dedicated local hotword dictionary, import previews, search, pagination and confirmed bulk deletion.
- Import TXT, XLSX, CSV, TSV and Sogou SGPU `.bin` files locally. Store up to 100,000 terms with a separate 100-enabled-term request budget.
- Add optional, default-off Windows correction candidates with bounded text-range observation and manual confirmation.
- Stop hidden dictation animations, spectrum painting and scroll updates. Suspend hidden Home and meeting view timers while preserving backend capture, ASR, autosave and summary work.
- Fix minimized-window restoration during dictation activation. All 82 shared regression scripts and the platform compatibility matrix passed before release preparation.
- Installer, portable build, updater metadata and SHA-256 checksums are provided. macOS releases remain independently maintained.
