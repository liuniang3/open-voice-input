# Open Voice Input v0.4.12

This release streamlines configuration and adds a local history for short voice input.

## Highlights

- Replaced the scattered settings flow with four vertical sections: Speech Recognition, Expression Organization, Speech History, and About & Updates.
- Consolidated dictation mode, microphone, shortcut, ASR supplier, API credentials and ASR model selection into the Speech Recognition section.
- Consolidated language-supplier management plus expression-cleanup and meeting/file summary model selection into the Expression Organization section.
- Added searchable local voice-input history with original text, organized text, timestamps, model labels and copy actions. Retrying a dictation updates the existing history entry instead of creating a duplicate.
- Excluded realtime previews, cancelled recordings, upload chunks and history entries from the saved history and usage statistics where they are not completed dictations.
- Added an option to disable saving new history entries without deleting existing history.
- Added in-app release-note rendering to About & Updates, with release HTML converted to inert plain text before display.
- Improved the shared Windows/macOS responsive settings layout and keyboard navigation.
