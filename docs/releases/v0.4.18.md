# Open Voice Input v0.4.18

本次更新修复首次引导中的供应商添加、主页快捷键响应及实时预览默认值，并将新用户引导的语音识别默认选项改为千问。

## 首次引导

- 未配置语音识别的新用户，默认选择「Qwen · 阿里云」和 `qwen3-asr-flash`，并启用实时预览。
- 保存后为千问匹配 `qwen-audio-3.0-asr-flash-streaming` 实时模型；非实时回退仍使用独立的批量识别模型。
- 对应 API 控制台入口同步显示为千问控制台，方便获取 API Key。
- 已有有效配置的 MiMo / 千问用户保留原来的供应商、自定义模型、地址、密钥和识别模式；仅打开引导不会覆盖已保存的设置。
- 表达整理供应商支持共享预设、明确的「添加供应商 / 保存连接」按钮、请求协议和认证方式选择，包括 MiMo 的 `api-key` 和 OpenCode Go 的 Bearer 认证。
- 模型列表获取失败时仍可手动填写模型 ID，保存时加入该供应商的模型列表；失败提示固定在导航按钮上方，便于重试。
- 保存过程中禁用表单编辑，避免重复提交和跨供应商凭据混用。

## 快捷键与默认模式

- 修复主页等工作区获得焦点时，语音输入快捷键可能不响应的问题，Windows / macOS 共用按键匹配逻辑。
- 快捷键录入、设置编辑、启动和录音状态具有独立保护，避免旧快捷键残留及重复开始录音；离开快捷键设置后结束按键捕获。
- 新安装默认使用实时预览；引导将识别模式同时保存到当前设置及模型配置，避免保存后被旧配置覆盖。
- 保留 MiMo 轮询预览和已保存的非实时识别偏好，不强制迁移用户配置。

## 统一语音识别默认项

- 文件转写、实时会议新增「跟随语音输入法」，作为未独立配置时的默认选项，不再各自写死供应商和识别模型。
- 修改语音输入法的识别模型后，处于跟随模式的功能同步使用对应供应商；千问按实时 / 文件用途匹配接口模型，避免将实时模型送入文件转写接口。
- 使用该供应商的语音识别连接地址和 Key，不借用表达整理供应商的凭据。
- 用户主动选择的独立模型仍单独保存；旧版已保存的工作区模型保留，也可在下拉框切回「跟随语音输入法」。正在进行的转录和历史重试仍固定原任务模型，不随设置变化中途切换。
- 「MiMo 音频复核」仍是明确指定 MiMo 的可选功能，不随默认 ASR 变更。

## 验证与安全

- 共享回归测试覆盖首次默认千问、已配置 MiMo / 千问兼容、自定义模型、模式保存、供应商添加和快捷键匹配。
- 本地完整共享回归测试 `66/66` 通过；另有浏览器布局和 Windows 实际 Electron 验证。
- Windows 实际 Electron 检查使用隔离设置和合成输入，验证引导保存及主页快捷键；浏览器检查覆盖窄窗口布局。
- Windows x64、macOS Intel x64 和 Apple Silicon arm64 发布构建分别运行共享测试。
- 发布输入和提交内容经过敏感信息检查，不包含用户 API Key、本地设置、录音、转写记录、诊断截图或供应商响应正文。

## 下载与限制

- Windows：安装版及便携版 EXE。
- macOS：Intel（x64）和 Apple Silicon（arm64）的 DMG / ZIP。
- 附带自动更新元数据、差分更新文件和 SHA-256 校验文件。
- macOS 包仍未签名；CI 构建通过不等于原生录音、权限、粘贴及视觉效果已完成真机验证。
- 模型服务可用性及整理质量仍取决于供应商与所选模型；本次不改变转写、会议音频保留及文本整理的模型输出限制。

## English Summary

- Fresh onboarding defaults to Qwen / Qwen3-ASR Flash with realtime previews and the matching API console. Configured suppliers, custom models, credentials and explicit batch preferences are preserved.
- Fixed language supplier creation in onboarding with shared presets, explicit save actions, protocol/authentication selection and manual model persistence.
- Fixed configured dictation shortcuts while the workspace is focused, with capture/editing guards and shared Windows/macOS key normalization.
- Realtime mode persists in both active settings and per-model profiles, keeping Qwen streaming and batch fallback model IDs separate.
- File/live ASR defaults follow the active dictation provider with transport-appropriate models. Explicit workspace choices and existing recording/history checkpoints remain independent; ASR credentials never come from language suppliers.
- Release packages include Windows installer/portable apps and unsigned Intel/Apple Silicon macOS DMG/ZIP files, update metadata and checksums. Native macOS behavior still requires hardware validation.
