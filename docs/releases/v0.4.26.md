# Open Voice Input v0.4.26 · Windows

本次为 Windows 独立更新，重点修复实时会议转录卡住、预览不再推进和暂停恢复后的延迟。macOS 由协作者单独维护，本次不发布 macOS 安装包。

## 更连续的实时转录

- 阿里实时识别连接正常时持续使用同一任务，不再按固定十分钟轮换，也不会因每 30 秒保存 Markdown 而截断识别。
- 录音、ASR 识别和 Markdown 自动保存各自独立运行。读取音频仍有内存边界，发送时使用小音频包，不影响长时间连续识别。
- MiMo 非实时备用转录保留供应商限制下的分段方式；完整原始音频和全长 WAV 始终保留。

## 修复卡住与恢复

- 麦克风、系统声音到达时间不一致时，不再让整条实时任务作废。尚未发送的音频重新读取，已发送部分建立独立修复任务，修复成功后才替换对应文本。
- 增加静音心跳、连接健康检查和持续有声却无新识别结果的检测。断线后自动退避重试，最多五次，保留已确认文本和手动重试检查点。
- 修复长时间暂停后恢复预览需要等待的问题。复用协作者提交 `8a72d3b` 的共享修复：仅在上传时跳过明确暂停形成的全零音频，保留本地完整时间线；不会将微弱的非零语音当作静音删除。
- 过期任务的迟到回执不会把仍需修复的音频错误标记为完成。

## 验证与下载

- 76 个共享回归脚本通过，包含 40 个预览案例、29 个传输案例及 16 个持久化音频集成案例；覆盖模拟 30 分钟连续转录、9 分钟暂停、双音轨迟到、自动重试和恢复。
- 共享变更已通过 Windows x64、Intel Mac x64 和 Apple Silicon arm64 CI；macOS 的 CI 结果仅用于兼容性检查，不代表真机验收或本次发布了 Mac 版本。
- 实际千问 Streaming API 使用约 38 秒合成语音和静音测试：一条连接收到 19 次实时结果、2 次最终结果，无传输错误。这不是多小时实机稳定性的保证。
- 安装版：`Open-Voice-Input-Setup-0.4.26-x64.exe`。便携版：`Open-Voice-Input-Portable-0.4.26-x64.exe`。
- 已安装 Windows 版可以在“关于与更新”中检查更新。附带自动更新元数据、blockmap 和 SHA-256 校验文件；Windows 包仍未签名。
- 升级保留本机 API 配置、历史记录及录音。提交和发布包不包含密钥、个人配置、真实录音、转写正文或诊断截图。

## English

- Windows-only release; macOS remains independently maintained by the collaborator.
- Keep healthy Alibaba realtime tasks continuous across autosaves and the previous timed rotation boundary.
