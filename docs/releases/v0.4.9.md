# Open Voice Input v0.4.9

发布日期：2026-10-03。

本次更新改进了文件与实时会议摘要的后台运行、流式生成、重试与预算控制，并将摘要结果统一为带证据来源的文章和思维导图。供应商管理与语音识别/语言处理凭证隔离能力也继续保留。

## 摘要生成

- 从文件页面或实时会议页面启动摘要后，切换到首页、设置或其他工作区不会取消任务；返回原页面时会恢复当前进度与最终结果，也不会重复发起请求。
- 文件摘要和实时会议摘要统一生成证据约束的连贯文章，同时保留层级思维导图与来源信息；旧历史摘要继续兼容显示与导出。
- 支持 Chat Completions 和 Responses 的增量流式响应，显示连接、思考、接收字符、等待和重试状态；摘要可主动取消，原始录音和原始转写不受影响。
- 对临时网络错误、提前 EOF、限流和明确的临时服务错误执行最多 5 次可取消重试，使用新的输出缓冲区并遵循服务端重试延迟。
- 按选定供应商和模型的上下文/输出能力规划摘要预算；超出预算时采用有界的分层压缩，未知模型使用安全的默认预算。
- 已完成的付费任务在传输超时设置变化后仍可复用；模型、推理设置、源内容或预算变化会生成独立结果，避免错误复用旧摘要。

## 供应商与兼容性

- 通用语言供应商添加流程支持 OpenCode Go 预设、模型发现、Bearer/api-key 认证和独立模型测试；保存失败时保留连接，删除供应商时显示受影响用途并保护正在使用的配置。
- 语音识别与语言处理继续使用分离的连接和凭证。ASR、文件转写、实时会议与可选音频核对不会借用语言供应商的 Key；摘要和表达整理不会回退到另一类凭证。
- 保留 MiMo api-key、Token Plan 和自定义端点的兼容路由，并对错误信息、IPC 和日志执行脱敏处理。

## 下载与升级

- Windows x64：
  - `Open-Voice-Input-Setup-0.4.9-x64.exe` 安装版
  - `Open-Voice-Input-Portable-0.4.9-x64.exe` 便携版
- macOS Intel：选择名称含 `0.4.9-x64` 的 DMG 或 ZIP。
- macOS Apple Silicon：选择名称含 `0.4.9-arm64` 的 DMG 或 ZIP。
- Windows 与两种 macOS 架构分别保留自动更新元数据、增量文件和 SHA256 校验文件。
- 升级不需要删除本机设置；发布包不包含 API Key、本机设置、录音、转写结果、供应商响应或诊断截图。

## 验证与限制

- 本地 `55/55` 共享回归脚本通过，包含后台摘要生命周期、流式响应、预算、重试、供应商路由、UI/IPC 和跨会话数据隔离检查。
- 当前源码 CI 已通过 Windows x64、macOS Intel x64、macOS Apple Silicon arm64 和 Linux 检查；本 Release 工作流会再次执行共享测试并构建发布包。
- macOS 发布包仍未签名、未公证；CI 和构建通过不等于麦克风、系统声音、粘贴或手势已完成 Mac 真机验收。
- 真实 ASR 与语言整理质量仍受录音质量、网络、供应商权限及模型表现影响。语言供应商需兼容应用支持的 Chat Completions 或 Responses 协议。
