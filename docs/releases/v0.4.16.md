# Open Voice Input v0.4.16

本次更新优化主页功能入口，并在表达整理设置中增加快速模型推荐提示。

## 更新内容

- 主页的「文件转写」和「实时会议转录」改为两个整块可点击的大卡片，移除卡片内独立的小按钮。
- 点击卡片仅进入对应功能页面，不再直接打开文件选择器，也不会自动开始会议录音。支持鼠标点击及键盘 Enter / Space 操作。
- 表达整理的模型选择框下方增加提示：「推荐优先使用 Flash 等快速模型，以缩短表达整理等待时间，提升语音输入法响应速度。」
- 提示不会更改已选择的模型、供应商、API 地址、Key 或模型参数。
- Windows 和 macOS 共用这些界面更新，并保持窄窗口布局适配。

## 验证与安全

- 本地共享回归测试 `58/58` 通过，覆盖主页导航、录音隔离、表达整理模型提示及现有转写/摘要功能。
- 浏览器测试检查主页和设置页在不同窗口尺寸下的显示、整卡点击及键盘操作。
- Windows Electron 导航测试使用独立测试配置，不调用真实 API，也不读取或发布用户凭证。
- 发布前的敏感信息扫描与 `git diff --check` 通过。发布包不包含 API Key、本地设置、用户音频/转写记录、诊断截图或供应商响应正文。

## 下载与限制

- Windows：安装版和便携版 EXE。
- macOS：Intel（x64）和 Apple Silicon（arm64）的 DMG / ZIP。
- 附带自动更新元数据、差分更新文件和 SHA-256 校验文件。
- macOS 版本仍未签名；CI 构建通过不等于原生录音、权限和粘贴功能已完成真机验证。
- 已知的 Windows 部分边缘缩放光标探测限制不在本次修复范围内。

## English Summary

- Home file-transcription and live-meeting entries are now full-card buttons. They open their workspaces only, without opening a file picker or starting recording.
- Expression Organization settings recommend Flash/fast models to reduce dictation latency, without changing existing configuration.
- Shared Windows/macOS UI, responsive layouts and accessible mouse/keyboard navigation are covered by regression tests.
- Release assets include Windows installer/portable packages and unsigned Intel/Apple Silicon macOS DMG/ZIP packages, with update metadata and checksums.
