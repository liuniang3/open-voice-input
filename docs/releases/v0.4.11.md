# Open Voice Input v0.4.11

This release fixes voice-expression cleanup when a named language supplier is selected.

## Highlights

- Recording snapshots now preserve the selected language supplier, model, model capabilities and provider connections.
- OpenCode Go cleanup no longer falls back to a stale MiMo Token Plan endpoint during realtime completion, segmented transcription or retry.
- The snapshot is deep-copied at recording start, so changing suppliers or models while a recording is being processed cannot change that request.
- Dictation cleanup uses the selected model's configured output limit instead of a fixed 2048-token cap.
- Cleanup validation rejects explanation-style or list-like model responses instead of inserting model commentary into the dictated text.
- Legacy hidden OpenCode Go migration entries no longer block adding a visible OpenCode Go supplier with the same display name.

## Verification

- Shared regression suite: `55/55` scripts passed.
- Secret scan passed.
- Live cleanup smoke checks succeeded through an existing local OpenCode Go connection with `mimo-v2.6-flash` and `deepseek-v4.1-flash`.

No API keys, local settings, audio, transcripts or provider response bodies are included in this release.
