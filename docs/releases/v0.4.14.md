# Open Voice Input v0.4.14

This release makes Expression Organization settings compact and moves provider administration into a dedicated in-app management page.

## Highlights

- The Expression Organization overview now shows only the selected dictation cleanup model and a compact provider summary.
- Added an in-app provider management subpage for adding, editing, deleting and testing language suppliers, synchronizing model catalogs and manually adding model IDs.
- Model capability settings are collapsed by default and remain editable per model, including context window and maximum output.
- Removed the duplicate meeting/file summary model selectors and capability fields from Expression Organization. Summary models continue to be selected in their respective workspaces.
- Saving dictation settings now preserves existing meeting/file summary selections, credentials and model capabilities.
- Kept the settings layout and navigation shared between Windows and macOS, including Back and Escape navigation from provider details.
- Updated the English and Chinese README documentation and added regression coverage for the compact settings flow, supplier management and summary UI contracts.

## Verification

- Shared regression suite: `57/57` scripts passed locally.
- Browser settings, supplier-management and window-layout checks passed.
- Secret scan passed; no API keys, local settings, user audio, transcripts, diagnostic screenshots or provider response bodies are included.
- `git diff --check` passed.

## Known limitation

- The Windows native edge-resize cursor probe still does not pass for every sampled edge. The application layout remains responsive, but this native cursor detail needs a separate platform-specific follow-up.

The release workflow builds and publishes the Windows installer/portable package plus unsigned Intel and Apple Silicon macOS DMG/ZIP packages.
