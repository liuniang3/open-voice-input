# Open Voice Input v0.4.17

本次更新集中改进语音输入浮窗的可读性、频谱稳定性和完整文本输出，并补充窗口动画与长文本阅读布局修复。

## 语音输入浮窗

- 浮窗固定为 340 × 116，录音、转写和表达整理期间不再被长文本撑大。
- 白色背景采用 80% 不透明度，文字保持不透明；保留 18px 圆角，去掉描边、白色内高光、文字阴影和录音指示点的白色光圈。
- Windows 使用独立的透明显示窗口，关闭原生 Acrylic/Accent 背景，修复失去焦点后发灰、不透底和圆角外出现矩形残底的问题。这是实际半透明显示，不是原生桌面模糊；macOS 保留其原生 vibrancy 实现。
- 实时预览不再显示冗余的「实时结果」标题，文本在固定区域内滚动且隐藏滚动条。默认跟随最新内容，手动向上滚动时暂停跟随，回到底部后恢复。
- 按完整行显示预览，减少顶部露出上一行碎片的情况；录音指示点与第一行文字居中对齐。
- 取消按钮更简洁，快捷键提示改为「Enter 输入 · Esc 取消」。

## 频谱与窗口动画

- 用真实麦克风驱动的频谱替换单条音量进度条，作为浮窗内的低对比度背景。
- 频谱独立定时采样，不再依赖隐藏录音页面的动画帧，修复柱子偶发卡住。声音变化、静音和恢复说话均持续更新。
- 短暂收不到频谱数据时回落到静音，不再停留在旧高度；进入文本处理后忽略迟到的频谱帧。
- 停止、取消和系统「减少动态效果」设置会清理相关视觉定时器，不改变录音 PCM 和 ASR 请求链路。
- 增加窗口淡入淡出、主页/设置/文件/会议页面切换及设置内容过渡。尊重系统「减少动态效果」偏好。
- 快速关闭后重开不会被旧动画再次隐藏，过期焦点重试也不会重新激活已关闭的窗口。

## 文本完整性与阅读布局

- 表达整理提示词明确要求从第一句处理到最后一句，保留完整意图、末尾要求和否定，不用省略号或占位符代替原文内容。
- 对供应商报告的输出截断、整理结果新增的末尾省略号增加校验；校验失败时保留完整 ASR 原文，不粘贴残缺的整理结果。
- 不降低用户设置的模型最大输出，不重新启用正则重复词替换；正常叠词和原文中的省略号仍受保留。
- 文件转写、文件摘要和实时会议摘要的段落使用阅读区域的可用宽度，修复提前换行；保留原有段落、时间戳和全文内容。

## 验证与安全

- 本地共享回归测试 64/64 通过。
- Windows 实际 Electron 测试覆盖 80% 不透明度、四角透空、失焦/重新弹出/淡出状态、长文本滚动和完整 Enter 输出。
- 用合成麦克风暂停录音页面的动画帧后，验证频谱变频、静音回落和恢复；不调用真实 API，也不使用用户录音。
- 发布流程分别构建 Windows x64、macOS Intel x64 和 Apple Silicon arm64，并运行各平台的共享回归测试。
- 发布前检查待提交文件及构建输入，不包含 API Key、本地设置、用户音频/转写记录、诊断截图或供应商响应正文。

## 下载与限制

- Windows：安装版和便携版 EXE。
- macOS：Intel（x64）和 Apple Silicon（arm64）的 DMG / ZIP。
- 附带自动更新元数据、差分更新文件和 SHA-256 校验文件。
- macOS 版本仍未签名；CI 构建通过不等于原生录音、权限、粘贴和视觉效果已完成真机验证。
- 表达整理仍依赖所选模型，完整性检查无法检测所有语义遗漏；原始识别文本应作为核对依据。
- 已知的 Windows 部分边缘缩放光标探测限制不在本次修复范围内。

## English Summary

- Compact fixed-size dictation popup with an 80%-opaque white surface, clean 18px corners, no outline and fully opaque text. Windows uses per-pixel translucency rather than a native Acrylic backdrop; macOS retains vibrancy.
- Full realtime text scrolls within the popup without a visible scrollbar or redundant title. Manual reading pauses automatic tail following.
- Timer-driven spectrum sampling remains responsive when the hidden recorder stops receiving animation frames. Silence, stale delivery, processing transitions and cancellation are handled explicitly.
- Added subtle window and page transitions with system Reduce Motion support and interrupted-animation protection.
- Cleanup prompts require complete coverage; truncated responses and newly introduced trailing ellipses fall back to the complete ASR transcript without reducing configured output limits.
- File and meeting transcript/summary paragraphs use their available reading width instead of wrapping prematurely.
- Release assets include Windows installer/portable packages and unsigned Intel/Apple Silicon macOS DMG/ZIP packages, update metadata and checksums. Native macOS behavior still requires hardware validation.
