# Open Voice Input v0.4.8

发布日期：2026-10-02。

本次更新主要重做供应商添加面板，并将语音识别与语言处理的设置、凭证和请求路由分开。升级保留已有 API 地址、Key、会议历史和完整音频，无需重新填写已保存的凭证。

## 语音识别与语言处理分开管理

- 设置增加独立的“语音识别供应商”与“语言处理供应商”分类。
- MiMo / 阿里云 ASR 连接用于短语音识别、文件转写、实时会议，以及可选的 MiMo 音频核对。
- 表达整理、文件摘要和会议摘要使用独立添加的 Chat Completions / Responses 兼容语言处理供应商，模型目录、API 地址、Key 和认证方式按供应商保存。
- 同一品牌也可以分别设置识别与语言处理的地址和 Key。修改一类不会覆盖另一类；清空 ASR Key 不会借用语言处理或旧模型配置里的 Key。
- 兼容文本接口不代表支持 ASR 音频协议，新增语言处理供应商不会自动成为语音识别供应商。

## 新的供应商添加面板

- 参考 CC Switch 的预设优先流程：先搜索、选择连接模板，再填写名称、地址、Key 和协议；支持自定义连接。
- 使用应用内独立新增/编辑窗口，展示实际请求路径，固定保存和取消区域；预设不内置 Key 或固定模型名称。
- 已保存连接和未保存草稿分开管理。取消或 Esc 在确认后丢弃草稿，保存其他设置不会误提交供应商草稿。
- Key 默认隐藏，可显示和复制；编辑时留空保留原有 Key。关闭编辑窗口会清空输入框，不清除本机已保存的凭证。
- 支持分别同步模型、手动添加模型 ID、选择具体模型测试连接，并显示模型数量与同步时间。同步失败保留旧目录。
- 支持 Bearer / api-key 认证，MiMo 模板使用 api-key。供应商名称重复时提示修改，内部 ID 默认自动生成。
- 使用中的语言处理供应商必须先取消或更换用途选择并保存，才可删除；删除后的旧迁移配置不会自动重新出现。
- 移除专门的实验性 OpenCode Go 入口，其旧连接仍可迁移到通用语言处理供应商列表。

## 迁移与使用体验

- 旧 ASR 连接、语言处理连接、已选语言模型及模型目录自动迁移；历史文件和原始音频保持不变。
- 首次配置引导只把 ASR 设置写入语音识别连接，快速模式的 ASR 配置测试不要求先配置语言模型。
- ASR 连接测试使用音频请求，不再用文本模型的回答来代替识别接口测试。
- 未配置或删除语言处理供应商时，语音输入安全保留原始转写；摘要生成提示补充配置，不会改用另一家的 Key。
- 设置分类栏改为可横向滚动的单行标签，小窗口不再因多行标签挤占配置区域。

## 下载与升级

- Windows x64：`Open-Voice-Input-Setup-0.4.8-x64.exe` 为安装版，`Open-Voice-Input-Portable-0.4.8-x64.exe` 为便携版。
- macOS Intel：选择名称含 `0.4.8-x64` 的 DMG 或 ZIP。
- macOS Apple Silicon：选择名称含 `0.4.8-arm64` 的 DMG 或 ZIP。
- 保留 Windows 和两种 Mac 架构各自的自动更新元数据、增量文件与 SHA256 校验文件。
- 无需删除本机设置后再升级。发布包不包含用户的 API Key、本机设置、录音、转写结果、供应商响应或诊断截图。

## 验证与限制

- 本地 52 组共享回归脚本通过；完成供应商新增、编辑、取消、密钥显示、模型同步、删除保护、配置隔离和响应式页面的浏览器测试。
- 源码 CI 已通过 Windows x64、macOS Intel x64、macOS Apple Silicon arm64 和 Linux 检查；发布构建重新执行各平台共享测试和打包流程。
- 安全扫描覆盖仓库源码与提交内容；测试使用合成凭证和模拟 API 响应，不上传用户录音。
- Mac 包仍未签名、未公证；自动更新可下载后打开本地安装包，不保证无提示自动安装。CI 和构建通过不等于麦克风、系统声音、粘贴或三指拖动已完成 Mac 真机验收。
- 真实 ASR 和语言整理质量仍受录音质量、网络、供应商权限及模型表现影响。任意语言处理供应商仅适用于已兼容的 Chat Completions / Responses 协议，不保证所有网关的特殊扩展参数都可用。
