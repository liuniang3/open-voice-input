# Open Voice Input v0.4.15

This release separates recent records on Home and simplifies speech-recognition supplier selection and API setup.

## Highlights

- Home now has two independent recent-record groups: meeting/file transcriptions and voice-input history. Groups appear side by side in wide windows and stack in narrow windows.
- Recent voice entries show a local text preview, timestamp and organization status. Clicking an entry opens its exact original/organized text in history, clears stale search filters and supports copying. The group also provides a shortcut to all voice history.
- Home refreshes when voice history changes and coalesces updates received during an active refresh. Voice-history read failures do not hide meeting/file records. Viewing history never calls a model or changes voice-input usage counts.
- Speech-recognition supplier selectors in Settings and first-run setup now show MiMo and Qwen / Aliyun only. Fun-ASR remains an Aliyun model/transport instead of a separate visible supplier. Existing model choices, keys, custom URLs and transport protocols are preserved.
- Added a supplier-aware API Console button in Settings and first-run setup to open the official MiMo or Aliyun Bailian API Key management page in the system browser. The IPC accepts only known suppliers from the local app, not arbitrary URLs, and does not send saved credentials.
- The recognition model picker now recommends Qwen3-ASR Flash instead of MiMo V2.5 ASR. Existing model selections and realtime-preview settings remain unchanged.
- Updated English/Chinese documentation and regression coverage. All UI and provider-display logic is shared by Windows and macOS.

## Verification

- Shared regression suite: `58/58` scripts passed locally.
- Homepage and Settings browser checks passed, including narrow-window layouts, exact history-entry navigation, API console controls, failure recovery and legacy Fun-ASR configuration retention.
- Windows Electron checks passed with isolated test settings and no live API calls; console destinations were intercepted rather than opening real browser sessions.
- Secret scan and `git diff --check` passed. No API keys, local settings, user audio, transcripts, diagnostic screenshots or provider response bodies are included in the release.

## Downloads and Limitations

- Windows installer and portable EXE, plus unsigned Intel and Apple Silicon macOS DMG/ZIP packages, are built by the release workflow. Each platform has update metadata, blockmaps and SHA-256 checksums.
- macOS builds are unsigned; CI build success does not replace a hardware check of native recording, permissions or paste behavior.
- The existing Windows native edge-resize cursor probe limitation remains outside this release's scope.
