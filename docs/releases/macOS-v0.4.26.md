# Open Voice Input Mac 版（macOS）v0.4.26

发布日期：2026-10-22。Mac 独立通道的首个候选版本，提供 Apple Silicon（arm64）和 Intel（x64）安装包。

## 改进

- **长会议暂停后恢复预览**：修复阿里云实时会议录制较长时间、暂停数分钟后继续，预览迟迟没有新文字的问题。恢复后跳过暂停时间空洞中的连续数字零样本，让新语音及时进入识别；极轻的非零声音仍完整上传。
- **记住会议摘要模型**：会议左下角切换“摘要模型”后，保存所选供应商与模型；重新打开页面和新会议读取最新设置。表达整理模型保持独立，保存失败会提示并恢复已保存选项。
- **Mac 独立更新**：本版接入仅面向 Mac 的更新源，Intel 与 Apple Silicon 分别读取对应安装包及具体改进说明。Mac 发布不会占用 GitHub 全局 latest，也不会向 Windows 用户推送 Mac 安装包；Windows 的发布流程保持原样。
- 原生 PCM、完整 WAV、确认文字和时间戳保留完整时间轴；暂停空洞只影响 ASR 上传。迟到音频使相应区间变为可重试，录音、转录和自动保存仍相互独立。

## 安装与迁移

1. 按芯片选择文件名中的 `arm64`（Apple Silicon）或 `x64`（Intel），下载 DMG。
2. 结束正在进行的录音/转录并退出旧版；打开 DMG，将 **Open Voice Input.app** 拖入“应用程序”，替换旧版。
3. 首次从 v0.4.25 及更早版本切换，需要手动安装本版；之后才会读取独立 Mac 通道的后续更新。

应用标识及本机用户数据目录保持一致。替换 App 不需要清理配置、凭证、历史或录音目录。ZIP 用于备用手动安装及更新下载，SHA256SUMS 文件用于核对对应架构安装包。

## 验证与限制

- 当前版本的本机 77/77 个共享回归脚本、arm64 DMG/ZIP 构建、镜像及原生资源探测和安装包校验通过。修复基线的 Ubuntu、Windows x64、Mac x64/arm64 CI 全部通过；候选提交的双架构构建结果记录在 GitHub Actions 与 `docs/MACOS_DEVELOPMENT.md`。
- 合成回归覆盖跨长连接轮换后暂停约 9 分钟、重复暂停、迟到音频与重试、摘要模型偏好记忆和供应商隔离，以及 Mac 更新源和安装包校验。
- 本版**未签名、未公证**。真实阿里云长会议、系统权限、真实采集、文字输入及实际安装仍待用户验收；构建与合成测试通过不代表这些硬件场景已通过。
- GitHub 将本版标记为 prerelease，且不设为全局 latest，用于与现有 Windows 更新器隔离。Mac 通道按稳定数字版本 `0.4.26` 比较后续更新。
