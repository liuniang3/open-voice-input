# Open Voice Input v0.4.25

本次更新修复主页和设置窗口打开时无法通过快捷键呼出语音输入法的问题，完善不经过剪贴板的文字输入，并修复语音弹窗的闪烁与文字闪动。

## 快捷键与窗口状态

- 主页或设置窗口打开、最小化、隐藏到托盘时，均可通过已配置的快捷键呼出语音输入法。
- 仅在实际编辑快捷键时暂停全局快捷键；窗口失焦、最小化、隐藏、切换设置页面或渲染进程异常后会释放编辑状态。
- 串行处理快捷键注销与注册，避免快速切换窗口导致全局快捷键失效；首次使用引导也采用相同规则。

## 直接输入与识别历史

- 语音输入法自动输入文字时不再改写系统剪贴板。Windows 使用原生 Unicode 键盘输入，macOS 使用原生辅助功能组件；用户主动点击复制按钮仍可复制结果。
- 修复 Windows 原生输入结构不完整导致文字无法写入的问题，验证中文、英文、表情、长文本、换行和制表符的完整输入。
- 输入前检查目标窗口；原生输入失败时停止并重新展示识别结果，不再误报已复制或记为成功输入。
- 托盘右键菜单增加“识别输入历史”，可在设置中配置独立快捷键，也可清空快捷键；检查与语音输入、实时会议快捷键的冲突。
- 移除托盘右键菜单中的“主页”“隐藏”“开始录音”；双击托盘打开主页的行为保留。

## 弹窗动画

- 修复从输入框位置展开的气泡弹窗首次呼出时准备首帧过慢的问题。
- 避免准备弹窗时意外显示之前隐藏的主页或引导页面，消除先闪出旧页面再出现录音弹窗的情况。
- 移除气泡展开结束后重复触发的文字淡入，避免内容短暂变淡、消失后重新出现。

## 验证与下载

- 76 个共享回归脚本通过；Windows x64、Intel Mac x64、Apple Silicon Mac arm64 的 CI 均通过。发布构建再次执行共享测试、原生组件构建与敏感信息检查。
- 本机 Windows 使用实际系统快捷键验证主页／设置的显示、最小化、托盘隐藏及快捷键编辑等 9 个场景，并在真实 Codex 输入框中录屏检查弹窗。文字输入测试覆盖普通文本框和富文本框，同时验证剪贴板格式及内容保持不变。
- Windows：选择 `Open-Voice-Input-Setup-0.4.25-x64.exe` 安装版，或 `Open-Voice-Input-Portable-0.4.25-x64.exe` 便携版。
- Apple Silicon Mac：选择文件名含 `arm64` 的 DMG 或 ZIP；Intel Mac：选择含 `x64` 的 DMG 或 ZIP。macOS 包目前未签名、未公证；原生采集、权限、直接输入和动画外观仍需真机验收。
- 包含自动更新元数据、blockmap 和 SHA-256 校验文件。已有用户可通过“关于与更新”检查更新；未签名 Mac 更新仍需替换下载后的应用。
- 升级保留本机供应商配置。提交与发布包不包含 API Key、个人配置、真实录音或转写、诊断截图及供应商响应正文。
