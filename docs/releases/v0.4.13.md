# Open Voice Input v0.4.13

This patch release supersedes v0.4.12 with the same settings and local voice-history features and completes the cross-platform release build.

## Fixed

- Stabilized the managed-stream cancellation regression test on slower Windows CI runners by waiting for the simulated provider request to start before triggering cancellation. The test still verifies that cancellation reaches the active request and that late output is not persisted.

## Included Features

- Four-section vertical settings navigation for Speech Recognition, Expression Organization, Speech History, and About & Updates.
- Consolidated ASR and expression-organization configuration flows.
- Searchable local short-dictation history with original text, organized text, timestamps, model labels, copy actions and retry deduplication.
- In-app release-note display with inert plain-text rendering.
- Shared responsive Windows/macOS settings UI and keyboard navigation.

## Verification

- Shared regression suite: `57/57` scripts passed locally.
- Secret scan passed.
- Windows, Intel macOS, Apple Silicon macOS and Linux checks passed in the release workflow.

No API keys, local settings, user audio, transcripts, diagnostic screenshots or provider response bodies are included in this release.
