# Open Voice Input v0.4.22

本次更新升级会议与文件转写后的内容整理：先用简短概览交代全貌，再按主题写成连贯文章，配合可交互的思维导图和原音回听，方便理解与复查。同时修复语音输入弹窗动画的闪烁问题。

## 主题文章与思维导图

- 会议和文件使用同一套整理逻辑：概览、主题章节和连贯段落，保留重要细节及原文依据。
- 思维导图顶层分支与文章章节按顺序对应。支持彩色曲线分支、缩放、平移、展开/收起、键盘操作和章节跳转；较大的导图默认收起到章节层级。
- 较窄的阅读区域可以切换导图与文章视图。已有历史摘要仍可阅读，新版结果采用独立缓存标识。
- 段落下可展开原文依据与时间范围。点击时间戳可定位播放本地保存的音频，包括实时会议的完整 WAV；有麦克风和系统声音两路时可以选择音轨，回听不调用 ASR。
- Markdown、TXT 和 Word 导出保留概览及主题标题；Markdown 包含章节链接，Word 使用标题样式。原始转写与完整音频保持独立保存。

## 语音输入弹窗

- 从光标或输入框边缘以小气泡展开，保留现有固定尺寸；靠近屏幕底部时优先向上展开，无法定位时使用居中动画。
- 显示前先在隐藏状态准备首帧，修复先闪出大窗口、消失后再出现的情况。
- 处理重复呼出、取消录音、页面切换和延迟首帧，避免迟到的动画重新弹出窗口。支持系统减少动态效果设置，手动拖动不会被动画拉回。

## 验证与下载

- 本地共享回归 `72/72` 通过，Windows x64、macOS Intel x64 和 Apple Silicon arm64 平台 CI 通过；正式发布构建再次执行共享测试、原生组件构建和敏感信息检查。
- 浏览器检查覆盖 Windows/macOS 样式及 720/1040/1440 像素布局、导图交互、章节跳转、原文定位和安全文本渲染；Windows Electron 检查覆盖本地导图依赖及完整会议 WAV 的播放、跳转和范围读取。
- Windows 提供安装版与便携版 EXE；macOS 提供 Intel 与 Apple Silicon 各自的 DMG、ZIP，附自动更新元数据、blockmap 和 SHA-256 校验文件。
- 安装包不包含用户 API Key、本地设置、音频、转写记录或诊断截图；升级沿用现有用户配置。
- macOS 包仍未签名，原生录音、权限、粘贴及动画外观仍需 Mac 真机验证。本轮摘要测试使用模拟接口与合成数据，没有以真实模型 API 评估新提示词的整理质量。

## English Summary

- Meeting and file summaries now share an overview and connected topic chapters, with matching mindmap branches and backward-compatible history.
- Explore a local interactive mindmap with curved branches, zoom, pan, expand/collapse, keyboard navigation and chapter links. Narrow panes switch between map and article views.
- Expand transcript evidence and seek preserved local audio, including full-length meeting WAVs, without new ASR calls. Markdown, TXT and Word exports retain the overview and chapter structure.
- Dictation expands from the caret as a bubble. Prepare its first frame while hidden to eliminate the initial flash, and handle cancellation, delayed preparation and Reduce Motion.
- All 72 shared regression scripts and Windows/macOS platform CI passed. Synthetic browser and Windows Electron checks cover reading, playback and animation; live-model summary quality and native Mac hardware behavior remain unverified.
- Windows installer/portable and unsigned macOS Intel/Apple Silicon packages include update metadata and checksums. Credentials, local settings, recordings and diagnostic files are excluded.
