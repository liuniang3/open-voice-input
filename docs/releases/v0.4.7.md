# Open Voice Input v0.4.7

本次更新集中改进主页面、初次配置、文件与会议摘要，以及实时会议悬浮窗。既有供应商地址、API Key、会议历史和完整音频继续保留，无需升级后重新配置。

## 主页面与快速上手

- 普通启动及空闲时双击托盘打开主页，不再直接进入设置。
- 显示当前语音输入快捷键、今日/本周成功输入次数与字数，以及最近的文件和会议记录。
- 新增可跳过、可重新打开的首次配置引导，覆盖 ASR、文本供应商、模型、麦克风与快捷键。
- 重绘应用、文件转写和实时会议图标，统一浅色半透明界面，补充 macOS 托盘模板图标。

## 供应商与摘要

- 支持独立添加多个 Chat Completions 或 Responses 兼容的文本供应商，各自保存 URL、Key 和模型目录。
- 语音表达整理与摘要使用供应商模型目录，可自定义模型；两种功能的模型选择互不覆盖。
- 文件与会议统一采用“原始转写 → 可选 MiMo 全音频复核 → 思维导图与连贯内容整理”的摘要流程。
- 移除当前界面中的独立校订操作，旧校订文件和历史产物保持可读；原始转写不会被摘要覆盖。
- 文件导出继续支持 Markdown、TXT 和 Word；前置设置可折叠，结果与摘要阅读区可拖动调整高度。
- 移除设置顶部的全局“测试连接”按钮，保留供应商各自的测试入口。

## 实时会议悬浮窗

- 开始录制后自动进入统一悬浮窗，取消手动“精简”档，记忆正常尺寸和位置。
- 录制状态改为红/黄/绿指示灯，提供字号滑块；顶部使用紧凑的置顶和返回详情图标。
- 隐藏队列数量、自动保存提示、“原始转写”和“实时草稿”等占用空间的标签。
- 可调整历史文字和实时文字的区域占比；较小窗口只显示当前实时文字。
- 小窗口的恢复按钮与字号、透明度滑块只在鼠标移入时显示；移出后隐藏，不受残留键盘焦点影响。
- 背景不透明度支持 0%–100%，移入时临时恢复默认 90% 背景，移出后回到保存值。Windows 的 0% 小窗口使用独立透明显示层，保留普通窗口的原生缩放框架。

## 长时间转录与数据保护

- 阿里流式连接轮换时，上一连接后台等待最终确认，下一连接继续发送新音频，减少每 10 分钟边界的串行停顿。
- 保持最终转写顺序、独立失败重试检查点、完整原生音频和 WAV，不因上传分段截短本地音频。
- 录制、ASR 请求、Markdown 自动保存仍相互独立；MiMo 复核与摘要仅在录制结束后由用户触发。
- 输入统计只保存本机日期、次数、字数与去重 ID，不保存转写内容；透明显示层不接收密钥或录音权限。

## 验证与限制

- 本地 50 组共享回归测试通过；完成浏览器交互测试及 Windows 实际窗口、完全透明像素与恢复尺寸测试。
- 跨越 20 分钟的连接轮换已做模拟回归；不保证真实网络和供应商延迟完全消失。
- 提供 Windows x64 安装版/便携版，以及 macOS Intel/Apple Silicon 构建。Mac 包仍未签名、未公证；构建与自动化通过不等于麦克风、系统声音、粘贴和三指拖动已通过 Mac 真机验收。
- 发布包不包含 API Key、本机设置、用户音频/转写、诊断截图或供应商响应。升级前无需清空这些本机数据。
