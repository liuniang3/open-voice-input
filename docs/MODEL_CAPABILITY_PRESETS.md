# 模型能力参数预设

“会议校订与总结”会按以下优先级填写上下文窗口、最大输出、推理等级和请求超时：

1. 模型列表接口返回且通过范围校验的能力元数据。
2. 项目内置的已知模型能力档。
3. 未知模型的通用保守预设：上下文 `256000`、最大输出 `8192`、推理等级留空、超时 `180000 ms`。

所有参数都可以在设置中修改。用户修改后，该模型会切换为手工配置，后续刷新模型列表不会覆盖这些值。

“兼容预设”只是应用层的初始值，不代表每个供应商网关都开放相同上限。供应商的模型列表接口如果返回能力字段，会覆盖兼容预设；用户在设置中手工保存的模型参数优先级最高，后续刷新模型目录不会覆盖。

供应商接口可能只返回模型 ID，不返回能力数据。此时应用会使用已知档或通用档，不会猜测更激进的上限。推理等级对未知模型默认留空，避免向不支持该字段的兼容接口发送无效参数。

摘要请求还会应用独立的预算保护：实际 `max_tokens` / `max_output_tokens` 取模型能力上限、上下文窗口四分之一和应用安全上限 `256000` 三者的最小值。该保护不再额外固定为 `32768`；因此大上下文模型可以使用更大的输出预算，同时仍为输入、结构化证据和上下文保留空间。
