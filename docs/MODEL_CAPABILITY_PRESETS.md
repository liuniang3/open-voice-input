# 模型能力参数预设

“会议校订与总结”会按以下优先级填写上下文窗口、最大输出、推理等级和请求超时：

1. 模型列表接口返回且通过范围校验的能力元数据。
2. 项目内置的已知模型能力档。
3. 未知模型的通用保守预设：上下文 `128000`、最大输出 `8192`、推理等级留空、超时 `180000 ms`。

所有参数都可以在设置中修改。用户修改后，该模型会切换为手工配置，后续刷新模型列表不会覆盖这些值。

## 已知模型

| 模型 | 上下文 | 最大输出 | 推理等级 | 超时 | 依据 |
| --- | ---: | ---: | --- | ---: | --- |
| `mimo-v2.5` | 1,000,000 | 128,000 | 留空 | 300,000 ms | [MiMo V2.5](https://mimo.mi.com/models/zh-CN/mimo-v2.5) |
| `mimo-v2.5-pro` | 1,000,000 | 128,000 | 留空 | 300,000 ms | [MiMo V2.5 Pro](https://mimo.mi.com/models/zh-CN/mimo-v2.5-pro) |
| `glm-5.2` | 1,000,000 | 128,000 | 留空 | 300,000 ms | [GLM-5.2](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.2) |
| `grok-4.5` | 500,000 | 32,768 | `high` | 300,000 ms | [xAI models](https://docs.x.ai/developers/models)；官方页未单列最大输出，应用采用保守值 |
| `gpt-5.4-mini`、`gpt-5.5` | 230,000 | 32,768 | 留空 | 300,000 ms | 兼容供应商保守档，不作为 OpenAI 官方上限声明 |
| `gpt-5.6-terra/luna/sol` | 272,000 | 32,768 | `high` | 300,000 ms | 兼容供应商保守档，不作为 OpenAI 官方上限声明 |

供应商接口可能只返回模型 ID，不返回能力数据。此时应用会使用已知档或通用档，不会猜测更激进的上限。推理等级对未知模型默认留空，避免向不支持该字段的兼容接口发送无效参数。
